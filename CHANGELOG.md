# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-20 (Initial Release)

### Added
- **Scenario Builder**: Intelligent architecture generation based on user constraints (DAU, latency, consistency).
- **React Flow Canvas**: Interactive drag-and-drop system design canvas.
- **Interview Mode**: 4-phase mock interview simulator with auto-grading report card.
- **Concepts & Case Studies**: 14 core/advanced concepts and 6 real-world case studies (Twitter, Uber, WhatsApp, etc.).
- **Community Gallery**: Browse and remix user-submitted architectures.
- **Blog & Newsletter**: SEO-optimized technical blog and newsletter subscription UI.
- **Save & Export Engine**: Save designs to LocalStorage, export to PNG/SVG, and share via URL encoding.
- **Keyboard Shortcuts**: Added support for Undo (Ctrl+Z), Redo (Ctrl+Shift+Z), and Save (Ctrl+S).
- **Mobile Responsiveness**: Stacked layouts for mobile devices and tablets.
- **SEO Optimization**: Integrated \`react-helmet-async\` for dynamic meta tags and routing titles.
